# Quiet Places — A Nature Gallery

Responsive Design final project with original gallery text and nine replacement photographs.

Website: https://kez-de.github.io/responsive-nature/

## Requirements

- Mobile first: one grid column and a 10px gap.
- From 772px: two columns, circular figures, and the last figure spans both columns.
- From 992px: square corners and every third figure spans both columns.
- Reduced motion: automatic scrolling replaces smooth scrolling.
- Dark mode: dark figures, pale yellow text, and black borders.
- Exactly four media queries, in that order; no `max-width` rules.

Open `index.html` in a browser. Styles are in `css/style.css`; all images are local.
Run `python3 test-responsive.py` on macOS with Google Chrome installed to check layouts,
user preferences, image loading, alt text, and text contrast.

Based on the [course starter](https://github.com/academic-innovation-online-learning/WD4E-Advanced_Styling_with_Responsive_Design/tree/main/RD-week4-final_project_starter).
